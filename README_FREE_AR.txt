أثَر AI — نسخة ويب قابلة للتثبيت كتطبيق (PWA) ومجانية التوزيع
============================================================

ماذا تحتوي؟
- واجهة عربية متجاوبة.
- ملفات PWA: manifest وservice worker وأيقونات.
- يمكن تثبيتها من Chrome على أندرويد بعد رفعها إلى استضافة HTTPS.
- نشرها على GitHub Pages مجاني عادةً للمستودعات العامة.

مهم: هذه ليست APK. إنها تطبيق ويب قابل للتثبيت من المتصفح (PWA)، ولا تحتاج دفع رسوم متجر التطبيقات كي يفتحها الناس عبر رابطك.
لاستخدام محادثة ذكاء اصطناعي حقيقي عبر مزود API قد تحتاج مفتاحًا وتكلفة من المزود. النسخة المحلية لا تحتاج API لكنها ليست نموذج AI حقيقيًا. لا تضع مفتاح API داخل نسخة عامة؛ استخدم خادمًا آمنًا إن أردت إطلاقها للناس.

طريقة نشر مجانية باستخدام GitHub Pages:
1. أنشئ حسابًا في GitHub (إن لم يكن لديك).
2. أنشئ مستودعًا عامًا جديدًا.
3. ارفع كل ملفات هذا المجلد إلى جذر المستودع: index.html وmanifest.webmanifest وservice-worker.js وأيقونات PNG.
4. من Settings > Pages، اختر النشر من فرع main ومن المجلد /(root)، ثم Save.
5. انتظر رابط GitHub Pages الذي يظهر لك. افتحه على هاتف Android في Chrome.
6. من قائمة Chrome (⋮) اختر "Install app" أو "Add to Home screen".
7. أرسل الرابط لأي شخص؛ يمكنه فتح التطبيق وتثبيته مجانًا.

المايكروفون:
- يحتاج HTTPS، لذلك يعمل بعد نشره على GitHub Pages، وقد لا يعمل عند فتح index.html محليًا.
- يعتمد الإملاء الصوتي على دعم المتصفح للخاصية واللغة.
- تأكد من السماح بإذن الميكروفون في Chrome.

الخصوصية:
- الملاحظات والإعدادات تُحفظ محليًا في المتصفح.
- لا تحفظ مفتاح API في موقع عام. التطبيق المنشور للناس يحتاج خادمًا لحماية المفتاح إذا أردت ربط نموذج AI.
